Project 06

Google Sheets Master Dashboard

A central reporting dashboard that auto-feeds 7 downstream reports in real time — reducing a 3-hour manual process to a 20-minute automated task.

Google Sheets AppScript Automation Reporting

The Problem

The team was manually compiling data from multiple sources into 7 separate reports every week. Each report required copying data, reformatting, applying filters, and cross-referencing other sheets. The process took approximately 3 hours per cycle, was error-prone, and by the time reports were finished, the data was already stale. Different team members created reports with inconsistent formatting and calculations.

The Solution

I built a single master dashboard in Google Sheets that serves as the central data hub. All 7 downstream reports pull from this one source of truth using IMPORTRANGE, QUERY functions, and AppScript automations. Data updates flow automatically — when the master sheet is updated, all 7 reports refresh in real time.

3 hrs → 20 min
Weekly reporting time reduced by 89%

Process & Workflow

1

Data Source Audit

Mapped every data input across all 7 reports — identified overlaps, inconsistencies, and manual transformation steps that could be automated.

2

Master Schema Design

Designed a normalised master sheet structure that captures all required data points once, with consistent field names and formats.

3

Report Template Build

Rebuilt each of the 7 reports as views of the master data — using IMPORTRANGE for cross-sheet references and QUERY for filtering and aggregation.

4

AppScript Automation

Built Google AppScript triggers for scheduled data refreshes, email notifications when reports are ready, and error alerts when data validation fails.

5

Team Training & SOP

Created documentation and trained the team on updating the master sheet, interpreting reports, and troubleshooting common issues.

Key Features

  • 01
    Single source of truth — all 7 reports derive from one master dataset, eliminating inconsistencies and version conflicts.
  • 02
    Real-time cascading updates — when the master sheet is updated, all downstream reports refresh automatically.
  • 03
    Automated notifications — AppScript sends email alerts when weekly reports are ready or when data validation issues are detected.
  • 04
    Error-proof formulas — IFERROR wrappers and data validation rules prevent broken references and incorrect calculations.
  • 05
    Self-serve reporting — team members can filter and explore data without touching the master sheet or breaking anything.
